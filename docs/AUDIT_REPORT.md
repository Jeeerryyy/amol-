# Engineering Audit & Remediation Report: Amol Veg Resto

**Repository:** `amol-veg-resto` (`main` branch)  
**Scope:** Full-stack engineering hardening across Security, Database Integrity, Backend APIs, Frontend UI/UX & Accessibility, Digital Menu Prerendering, DevOps/CI, Automated Testing, and Documentation.

---

## 1. Confirmed Defects Identified & Resolved

| ID | Severity | Category | Component / File | Root Cause & Impact | Remediation Applied |
|---|---|---|---|---|---|
| **SEC-001** | **Critical** | Auth / Session | `server/middleware/auth.js` | `validateSession` and `destroySession` used `s.token LIKE $1 \|\| ':%'`, allowing a crafted `%` session cookie to wipe all admin sessions on logout and weaken lookup guarantees; memory store skipped expiry checks and fell through even when DB was online. | Enforced strict 64-hex token regex validation, switched SQL lookup/delete to `SUBSTR(token, 1, 64) = $1 AND SUBSTR(token, 65, 1) = ':'`, checked memory session TTL, and restricted memory fallback solely to DB-offline errors. |
| **SEC-002** | **Critical** | Auth Backdoor | `server/routes/authRoutes.js` | Catch block on `SELECT ... FROM owner` accepted hardcoded literal admin credentials when DB threw an error. | Removed hardcoded credential bypass completely; DB failures now fail closed with HTTP `503`. Also validated `PUT /auth/credentials` via Zod and revoked other sessions on password update. |
| **SEC-003** | **Critical** | XSS / Menu | `public/menu/index.template.html`, `scripts/prerender-menu.mjs` | Dynamic dish fields, categories, tags, and modal action button labels/URLs were interpolated unescaped into HTML / `innerHTML`. | Added `escapeHtml()`, JS attribute escaping, `safeMediaUrl()`, and `safeActionHref()` across runtime rendering and static prerendering; fixed malformed noodle-bowl SVG Bezier path in `prerender-menu.mjs`. |
| **SEC-004** | **High** | AuthZ / Redirects | `server/routes/adminRoutes.js`, `server/routes/publicRoutes.js` | `GET /api/admin/qr-codes/:id/download` bypassed `requireAuth`, lacked `try/catch` and rate limiting; QR/button destinations did not block `javascript:` or `data:` URI schemes. | Protected `/qr-codes/:id/download` behind `requireAuth`, added `try/catch` + `checkDownloadRateLimit()`, and validated redirect/button URLs with strict protocol allowlists (`http:`, `https:`, `/`, `#`, and `tel:`/`mailto:` for action buttons). |
| **SEC-005** | **High** | CSV Injection | `server/services/exportService.js` | CSV cell values starting with `=`, `+`, `-`, `@`, `\t`, `\r` were unescaped; `exportScansCsv` lacked quote escaping and threw 500 on malformed dates. | Added RFC 4180 CSV quoting + formula neutralization (`'`) and validated optional `from`/`to` dates cleanly (HTTP `400` on invalid dates). |
| **SEC-006** | **High** | CORS / Proxy / Startup | `server/index.js` | Missing `app.set('trust proxy', 1)` broke proxied IP rate limiters; blanket `cleanOrigin.endsWith('.vercel.app')` permitted arbitrary third-party Vercel domains with `credentials: true`; `initDatabase()` raced incoming requests. | Enabled `trust proxy`, restricted CORS to configured `ALLOWED_ORIGIN`, `SITE_URL`, deployment `VERCEL_URL`, and local dev origins in non-prod, and added `ensureDbReady()` middleware + exported `dbReadyPromise`. |
| **DB-001** | **High** | Dual-Engine DB | `server/db/connection.js`, `server/db/migrations.js` | Naive `sql.replace(/\$\d+/g, '?')` broke SQLite queries reusing positional placeholders (`WHERE id = $1 OR slug = $1`); `migrations.js` ran SQLite-only `PRAGMA` unconditionally on Postgres; missing `isPostgres` import broke slug check log cleanly. | Built `translateSqlToSqlite()` outside string literals, guarded `PRAGMA` vs `information_schema.columns` via `isPostgres`, normalized Postgres `COUNT(*)` with `Number(...)`, and stripped legacy `TODO` draft lines from existing `legal_pages` rows. |
| **BUG-001** | **High** | Pricing Engine | `server/services/pricingService.js`, `server/routes/adminRoutes.js` | Global price recalculation overwrote `dish_variants` of `special_only` dishes and treated `0%` markup as `10%`; `POST/PUT /dishes` coerced `special_price_override = 0` to `null`. | Restricted global variant recalculation to `scope = 'both'` dishes, preserved `0` markup and `0` special overrides, and replaced `Math.random()` IDs with `crypto.randomUUID()`. |
| **BUG-002** | **High** | Zod v4 Errors | `server/routes/authRoutes.js`, `server/controllers/reviewGenController.js`, `server/validation/schemas.js` | Installed `zod` exposes `.issues` rather than `.errors`, causing validation error handlers to throw `TypeError` (500); `schemas.js` had `scope` enum drift (`special_only`) and lacked credential/contact schemas. | Updated validation handlers to `.issues?.[0]?.message`, aligned `dishSchema`, and added `changeCredentialsSchema` & `contactInquirySchema`. |
| **BUG-003** | **High** | Navigation / Contact | `src/components/Navbar/Navbar.tsx`, `src/pages/ContactPage/*`, `server/routes/publicRoutes.js` | Subpage nav turned `/menu/` into `#//menu/`; mobile drawer showed outdated address/hours; Contact form discarded submissions, linked to wrong CID map URL, and missed `.form-input` responsive CSS rules. | Preserved `/menu/` links cleanly on subpages, synced mobile drawer address/hours from `siteConfig`, added `contact_inquiries` table + rate-limited `POST /api/public/contact` + Admin `/api/admin/inquiries`, fixed Maps URL & mobile CSS selectors. |
| **BUG-004** | **Medium** | Public / Menu / API Fallbacks | `server/routes/publicRoutes.js`, `public/menu/index.template.html`, `src/pages/GalleryPage/GalleryPage.tsx`, `src/components/Footer/Footer.tsx`, `src/pages/LegalPage/LegalPage.tsx`, `src/siteConfig.ts`, `index.html`, `scripts/update-index-html.mjs` | Public fallbacks emitted `mapsUrl` / `content` instead of `maps_url` / `content_html` and omitted `buttons`; menu video path compared relative vs absolute URLs; Gallery pill counts ignored dynamic `itemsList` and linked CTA to `#popular-dishes`; empty social/credit links rendered `href="#" target="_blank"`; visible `TODO` copy and literal verification token meta placeholders shipped in HTML. | Aligned fallback schemas, compared normalized video URLs, matched variants by `data-variant-id`, computed dynamic Gallery counts & updated CTA to `/menu/`, removed broken placeholder links/visible `TODO` text, and made verification meta tags opt-in via build env vars. |
| **UI-001** | **High** | Admin Styling | `src/admin/Admin.css`, `src/admin/AdminMenus.tsx`, `src/admin/AdminWebsite.tsx` | Missing CSS variables (`--admin-primary-action`, `--admin-text-dark`, `--admin-card-bg-subtle`) and ~16 layout/modal/KPI/toast utility classes across `Admin*.tsx`; SEO cards lacked `page_name` from backend; button preview used white text on light backgrounds. | Defined all missing CSS custom properties & classes cleanly in `Admin.css`, derived `page_name` in `GET /api/admin/seo-pages`, and computed luminance contrast color in `AdminMenus` live button preview. |
| **A11Y-001** | **Medium** | Accessibility / Performance | `src/pages/ReviewPage/ReviewPage.tsx`, `.css`, `src/components/Testimonials/TestimonialsSection.tsx`, `src/components/PopularDishes/PopularDishes.tsx` | Interactive `<button>` nested inside `<label htmlFor>` in star rating; hidden `.testimonials-pager` remained in DOM; `ReviewPage` timers lacked `.finally()` cleanup; polling ran while tabs were hidden. | Replaced nested label/button structure with accessible `role="radio"` star buttons keeping CSS & test selectors intact, conditionally rendered pager only when >2 reviews exist, cleaned up timers, and added `document.hidden` visibility checks to polling intervals. |
| **CLEAN-001** | **Medium** | Repo & DevOps | `public/popular-dishes-*.png`, `modal-*-preview.png`, `LeafDecor.tsx`, `SectionDivider.tsx`, `README.md`, `tests/*`, `.github/workflows/ci.yml` | Temporary Playwright PNGs sat inside `public/` (shipped in `dist/`); unused dead components existed; root `README.md` held the icon pack README; `test-total-system-audit.mjs` hung open without `browser.close()`. | Removed temporary screenshots (redirected sync test screenshot to gitignored `test-results/`), deleted verified dead `LeafDecor.tsx` & `SectionDivider.tsx`, authored complete root `README.md`, updated `docs/*`, fixed `browser.close()`, added `tests/security-and-integrity.test.mjs` (`npm run test:unit`), and added GitHub Actions `.github/workflows/ci.yml`. |

## 2. Architecture & Verification Notes

- **Verified Account / Operational Reference:** Default owner email configured via `ADMIN_EMAIL` (`owner@amolvegresto.in`); authentication uses `bcryptjs` + database-backed 256-bit hex tokens + CSRF enforcement.
- **Automated Quality Gates:**
  - `npm run test:unit` validates SQLite `$N` translation, CSV injection neutralization, special pricing scope isolation, CORS origin allowlisting, session wildcard attack prevention, QR download auth enforcement, dish `0` overrides, `/api/public/contact` persistence/XSS stripping, and session revocation on password updates against an isolated temporary SQLite database.
  - Playwright suites verify Homepage, `/menu/`, `/special-menu`, `/about`, `/gallery`, `/contact`, `/review`, `/privacy-policy`, `/terms-and-conditions`, `/qr/*`, and `/admin` across desktop (`1440px`), tablet (`768px`), and mobile (`390px`/`375px`/`360px`) viewports.
  - All checks and production build verification commands executed after the final repository edits are reported in the final delivery report.
